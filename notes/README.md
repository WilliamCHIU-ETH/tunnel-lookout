# 開發筆記

[← 回到 README](../README.md)

README 與 docs/ 講的是系統「應該怎麼運作」。開發筆記記錄的是實際開發時遇到的問題：哪裡卡住、怎麼找到原因、怎麼解決，以及事後學到什麼。

每篇筆記獨立成檔，放在這個資料夾。

## 每篇筆記的結構

| 段落 | 回答的問題 |
|---|---|
| 背景 | 當時在做什麼？牽涉到哪個部分？ |
| 症狀 | 出了什麼狀況？錯誤訊息是什麼？ |
| 定位 | 怎麼縮小範圍、找到真正的原因？ |
| 解決 | 做了什麼修正？為什麼這樣修？ |
| 驗證 | 怎麼確認真的修好了？ |
| 事後 | 學到什麼？還有什麼沒做？ |
