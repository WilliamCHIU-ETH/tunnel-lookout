# 限制與未驗證的事

[← 回到 README](../README.md)

這份文件集中列出入隧前還沒做到、或還沒驗證的事。其他文件描述的是系統的設計，這裡說明設計以外的實際狀況。

## 產品

- **選道效果沒有驗證**：某個測站在某一刻比較快，不代表選那條車道就能更快通過整段隧道。入隧前提供的是判斷依據，不是保證。
- **沒有推廣，沒有使用數據**：服務已經上線，但沒有在社群宣傳，所以沒有使用者數量或回饋可以引用。
- **推播通知沒有正式上線**：程式有推播功能，但沒有正式設定、沒有自動觸發，也沒有在真實裝置上驗證過送達。

## 資料來源

- **台灣 IP 的需求未經官方證實**：把資料收集放在台灣主機，是根據一次驗證做的判斷（見[架構](architecture.md)）。高速公路局是否有正式的地區限制，沒有找到官方文件。
- **部分來源不是正式 API**：排隊與事件資料讀取的是 1968 網站頁面實際使用的 JSON。官方沒有承諾格式會維持穩定，隨時可能改變。
- **官方資料本身可能延遲**：資料舊了，責任可能在官方；入隧前能做的是發現並標示，無法讓它變新。

## 系統

- **沒有備援**：只有一台主機。主機故障時，網頁、API、資料收集與影像轉送會一起停止。
- **Observer 沒有檢查所有資源**：每分鐘的全面檢查涵蓋服務、主要車道資料、資料收集、磁碟、備份與版本，但不直接檢查事件與 CCTV 的資料新鮮度。
- **備份的日常檢查有限**：Observer 只確認備份檔存在而且夠新；能不能真的還原，要靠另外的隔離還原檢查，部署切換前會做一次。
- **保護閘門的範圍偏大**：`package.json` 是整個檔案比對，改到開發用指令也會被擋。縮小檢查範圍的改進還沒做（見開發筆記〈[部署被保護閘門誤擋](../notes/2026-09-19-deploy-gate.md)〉）。
