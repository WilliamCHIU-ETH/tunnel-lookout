# AI 協作

[← 回到 README](../README.md)

入隧前主要是用 AI 開發工具（Codex、Claude Code）完成的。這份文件說明我負責什麼、AI 負責什麼。

## 分工

**我做的**
- **UI 風格與資料呈現邏輯**：畫面長什麼樣子，以及資料要怎麼呈現給用路人。
- **開發環境建置**：
  - 本機開發環境
  - 雲端開發環境：有想法時，可以直接用手機讓 Claude Code 或 Codex 開 PR 進行開發
  - CI/CD 流程的建立
- **主機**：選擇 VPS 服務商、付費、SSH 登入。
- **架構決策**：把資料收集搬到台灣主機（見[架構](architecture.md)）。
- **需要 root 的主機維護**：例如保護閘門的記錄更新，由 AI 寫好腳本、我在主機上親自執行（見[部署](deployment.md)）。

**AI 做的**
- 程式碼：網頁、API、資料收集程式
- 主機上的部署設定：systemd、Nginx、Cloudflare 加密通道、自動部署程式
- 大部分專案文件與維運手冊
